# Optimising-Campaign-Targeting-for-Policy-Renewals-Using-Household-and-Purchase-Behaviour

## Overview
This project focuses on using data analytics to improve the effectiveness of policy renewal campaigns for an insurance company. Leveraging demographic and behavioural data, i will explore how to segment customers, identify key drivers of campaign response, and build a data-driven targeting strategy that increases conversion rates while reducing marketing costs.
